# Fate Core Character Generator Agent Project

**Date:** December 28, 2025
**Status:** In Progress

## Objective
Create a specialized AI agent (`fate-character-generator`) to facilitate the creation of Fate Core characters. The agent will guide users through the structured process of defining High Concepts, Troubles, Aspects, Skills, and Stunts, ensuring adherence to the Fate Core System Reference Document (SRD).

## Key Features
- **Structured Workflow:** Follows the "Context, Role, Interview" (CRI) framework adapted for RPG character creation.
- **Rules Adherence:** Enforces the Skill Pyramid (+4, +3, +3, etc.) and Refresh/Stunt mechanics.
- **Creative Assistance:** Proposes specific Aspects and Stunts based on user concepts using "A/B/C" selection options.
- **Documentation:** Automatically generates a formatted Markdown character sheet upon completion.
