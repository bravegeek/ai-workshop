# Hidden Dreamers: Session Log

## Project Overview
**Hidden Dreamers** is a tragic sci-fi/techno-noir project exploring a universe where the collective unconscious (The Psychosphere) is a physical dimension that can be mined for data.

## Session Info
- **Date:** 2026-01-04
- **Phase:** World-Building & Act 1 Setup.

## Key Narrative Arcs
- **The "Techno-Mage" Logic:** IO uses code and artifacts (Psyloc-Shards) to impose logic on the dream.
- **The Tragedy:** The mission is a rescue op for IO's sister, Nia, who is trapped/bonded to a Sleeping God (The Unbroken Tongue).
- **The Mechanic:** The "Tides" of the Deep are controlled by the God's REM cycle.
